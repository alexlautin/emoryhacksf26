What this number means

100 means Lookout has not seen a risky action yet. Points come off for secrets, uploads, things that keep running later, risky commands, unknown servers, and package installs. Clear, Steady, Review, and Act are names for ranges of that number.

        Reading the page

        Alerts

        Dangerous events always show a banner on this page. On a Mac, Lookout also posts a system notification when you run it in a terminal. The menu bar app uses the system notification. Browser alerts stay off until you allow them.

        Normal for a project

        Mark a low or medium action from the activity list. Lookout does not learn this on its own. It will not hide a decoy read, or anything Risky or Dangerous. Removing a mark puts the points back.
